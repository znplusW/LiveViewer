# LiveViewer v1.0 — 在 Windows 上，长按重温 iPhone 实况照片

> Windows 11 x64 · GPL-3.0 · 绿色免安装。

把 iPhone 照片导到电脑后，实况不必停留在一张静态封面。LiveViewer 将同名 HEIC/JPG 与 MOV 作为一张 Live Photo 浏览：长按播放，松手回到照片，并支持声音。

## 本版亮点

- **触屏看图自然直接**：滑动切图、双指缩放、双击放大/还原、拖动平移与长按播放。
- **独立全屏预览**：主窗口选图、预览窗展示；初开最大化，移动到合适位置后再进入全屏。
- **虚拟触控板**：整块操作区域控制预览中的翻页、缩放、平移和播放，支持停靠或浮动。
- **本地图库浏览**：全览、可调整位置的胶片条、文件夹勾选、搜索筛选和按需缩略图缓存。
- **逐帧选择新封面**：保存 HEIC＋MOV 时同步处理配对标识和封面时刻，支持保存副本。
- **紧凑界面**：照片分辨率位于文件名下方；声音、缩放、适应集中在上方；统计移到左栏，给照片和缩略图留出更多空间。
- **GPL-3.0 开源**：无需账号，本地处理，不上传照片。

## 安装

下载 `LiveViewer-Windows-x64-v1.0.zip`，完整解压后运行 `LiveViewer.exe`。不要单独取出 EXE，保留 `_internal` 文件夹。

适用于 Windows 11 x64。默认静音，可通过声音图标开启；`Space` 按住播放、`P` 播放一遍、`F` 显示/隐藏胶片条、`F11` 切换全屏。单击照片不切换胶片条。

## 使用边界

封面帧取自视频，像素尺寸可能低于原始照片；覆盖保存无法撤销，保存副本可保留原组。第三方回导 iPhone 的结果取决于导入工具、系统和媒体，不能承诺所有组合都兼容。

本轮正式自动验证：826项回归零失败、零跳过；原生探针22项、真实窗口属性读回1项；源码和冻结EXE各72项、正常启动及退出审计均通过。两套自检各核验37份原生快照、9次关闭前真实属性清除和3次销毁句柄拒绝。真实触屏/触控板体验沿用此前用户在实体设备上的验收，不以自动注入冒充本轮硬件复测。

开发者附件 ExifTool-13.38-pinned-runtime.zip 仅用于按固定pin复现构建；普通用户只需下载绿色程序ZIP。对应源码入口见 [SOURCE-ACCESS-v1.0.md](https://github.com/znplusW/LiveViewer/releases/download/v1.0/SOURCE-ACCESS-v1.0.md)，第三方原许可随程序保留。
