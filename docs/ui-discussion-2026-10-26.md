## 已确认的布局方向

1. 大品牌头压缩为紧凑工具栏，保留 LiveViewer 名称。宣传语移至欢迎页或关于页面，具体位置在实施时确定。
2. 有照片后降低“添加文件夹”的视觉强调；空图库仍可突出添加入口。
3. 全览保留左侧文件夹栏，顶部一行搜索、筛选、排序，下方直接显示照片网格。
4. 全览不再常驻一整行文件名、LIVE、前后翻页、独立窗口等单张相关控件。选中照片后按需提供相关操作，避免这些控件长期占据一整行。

## 已确认的长文件名交互

鼠标悬停文件名时，通过悬停提示展示完整文件名和所在文件夹路径等详细信息。查看这些信息不需要点击菜单；取消此前建议的“更多 → 文件信息”入口。此调整针对文件信息入口，不涉及其他操作菜单。

当文件名因空间不足而省略中间部分时，双击文件名区域，直接复制原始完整文件名。

- 复制内容包含完整名称和扩展名，不包含所在文件夹路径。
- 复制使用原始文件名，保留原有字符和大小写，不包含显示时额外插入的省略号。
- 用户无需先展开文件名或等待悬停提示，也无需再执行一次复制操作。
- 该要求针对省略显示的文件名，作用于文件名文字区域；照片本身的双击行为维持原样。

示例：显示为 `2026-10-26_杭州…_0032.HEIC` 时，双击复制的内容为原始名称 `2026-10-26_杭州西湖_家庭旅行_精选照片_0032.HEIC`。

## 最新确认的 v1.0 布局修订

以下由用户最终“确认”，替代下方旧底部工具行布局：

- 删除最底部常驻的分辨率和路径状态栏。原图分辨率移至文件名正下方，小号灰字，不随缩放比例变化；路径仍可通过文件名提示及既有文件操作查看。
- “顶部”指文件名所在信息栏。按声音图标、减号、比例／适应窗口字样、加号、适应的次序放置图片控件，保留 LIVE、独立预览、计数和“…”菜单。文件名现有复制行为不变。
- 声音按钮只用线条图标：静音为喇叭与叉，有声为喇叭与声波；悬停说明点击后的动作，适配深浅主题，保留触控大小。
- 设置增加“显示缩放按钮和比例”，默认开启并保存选择。关闭时一起隐藏减号、比例／适应窗口字样、加号；声音、适应以及手势缩放继续可用。
- 底部胶片条右侧独立固定窄列，从上到下 X、左侧、右侧，不遮挡缩略图或随内容滚动。X 为隐藏胶片条，顶部胶片条开关可恢复；竖向胶片条沿用原来的操作和位置。
- 文件夹栏底部依次放置项目／LIVE 数量、待分析／缓存状态两块统计，再放“按住鼠标/触屏/Space播放”提示；保持原统计内容，快捷键随设置变化。隐藏侧栏时，统计和提示一起隐藏。胶片条彻底移除信息行，把释放的空间用于缩略图。
- 删除文件名栏上一张／下一张按钮，方向键和手势保留。删除照片下方整条播放和缩放工具行，让照片区域直接接胶片条分隔条。
- 窄窗口保留文件名最低宽度和触控目标。独立预览入口可收进现有“…”菜单，宽度足够恢复按钮；同一功能一直可达。
- 不改既有输入、全屏、预览关闭链和封面保存流程；真实窗口测试须另获用户确认，结束及时通知可以操作电脑，不自动提交 Git。
