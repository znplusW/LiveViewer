这个软件是用来看 iPhone 导入到 Windows 电脑的 Live Photos。
导入时可以使用爱思助手导入到 Windows 上，每个 Live Photo 会分别有一个同名的视频文件和图片文件。

LiveViewer 使用说明（v1.0）

解压整个文件夹后运行 LiveViewer.exe，保留 _internal 文件夹。

v1.0按已确认清单调整界面，封面编辑沿用09方案；本轮验证结果见随附验证记录。原HEIC与原JPG组的独立工具结果均已确认单一LIVE、新封面、画面及声音正常；本次LiveViewer集成另行验证。保存后的同名HEIC与MOV，请一起通过爱思助手“导入实况照片”导入。

顶部为保留 LiveViewer 名称的紧凑工具栏；有照片后降低添加入口的强调。全览保留文件夹栏，搜索、筛选、排序集中为一行，下方显示网格；单张相关操作按需提供。

原图分辨率显示在顶部文件名下方；声音图标、缩小、缩放比例、放大和“适应”集中在同一信息栏。设置中关闭“显示缩放按钮和比例”可一起隐藏减号、比例和加号，手势缩放及“适应”仍可用。窄窗口的“独立预览窗”入口收进“…”菜单，放宽窗口后恢复。

底部胶片条右侧固定排列“X / 左侧 / 右侧”，从上到下点击可隐藏或调整位置；顶部“胶片条”可重新显示。项目／LIVE 数量和待分析／缓存状态两块统计移至左侧文件夹栏底部、按住播放提示上方；隐藏文件夹栏时，统计和提示一起隐藏。胶片条不再保留信息行，将空间留给缩略图；底部原工具栏和路径状态栏已去除。方向键和手势切图照常使用。设置里的“退出全屏手势”可用触屏轻点一次展开。

1. 点击“添加文件夹”，可用 Ctrl／Shift 一次多选，追加到已有图库，默认扫描子目录。侧栏右键可从软件移除已选目录或指定目录及其子目录；不删除文件，重新导入可恢复。路径旁的“隐藏列表／显示列表”开关侧栏。点击目录左侧复选框可多选，子目录独立勾选；普通点击名称只记录范围起点，不改变勾选，随后按住 Shift 点击另一个目录可选中这之间的范围。按住 Ctrl 从名称或空白处拖框，框内已选目录取消勾选、未选目录变为选中，框外保持不变；中途松开 Ctrl 则取消本次框选。Ctrl+A 全选。搜索范围为“已选文件夹”或“全局”（全部已导入）。全览可上下滑动；双指张合或 Ctrl+加号／减号调整预览大小与每行数量。
2. LIVE 图片上长按鼠标左键、单指或空格播放，松开停止；P 播放一遍。全览和胶片条的 LIVE 标记位于缩略图单元框内的左上角，减少遮挡图片；小缩略图用圆点，放大后恢复完整标记。设置可开启切图后自动播放，默认关闭。
3. 图片及空白处均可左右滑动切图；双指缩放、放大后拖动。竖向滚轮缩放；未放大时水平滚轮始终翻页，放大后按“放大时水平滚轮”设置翻页或平移；双击切换适应窗口／两倍放大。放大时右下角小图标出当前可见范围，可点击或拖动定位；触控板轻触两下，第二次只保持接触、不压下实体按键，停顿后拖动仍只平移；明确按住实体按键播放，松开停止。
4. 主窗用 F11 进入／退出全屏，保留全览或单张。Esc 先退出主窗全屏，再返回全览；F 开关胶片条。单击照片不改变胶片条状态，可通过按钮或快捷键控制。胶片条用 X 关闭，“左侧／右侧／底部”直接切换位置；横排左右滑、竖排上下滑，轻点选图，竖排滚动条在外侧。拖动靠照片一侧的分隔条调整大小；方向、位置和横排高度／竖排宽度分别记忆。“退出全屏手势”仅有“屏幕上沿下滑”，默认开启，取消勾选可关闭。手势等同 Esc；独立预览退出全屏时直接收回主窗单张，并关闭触控板。
5. 顶部文件名仍可选取复制；悬停可查看完整名称和文件夹路径。发生省略显示时，双击文件名文字区域，直接复制原始完整名称和扩展名，不含路径；照片本身的双击缩放不变。右键可选择其他应用、更换静态来源，或打开所在文件夹并选中当前图片。
6. 右键“更改封面图”可用鼠标或单指触屏拖动时间轴、连续逐帧预览，并标记原封面图的匹配位置；窗口可最大化。预览支持缩放和拖动，右键“导出静帧画面”可另存全尺寸 PNG/JPG/HEIC。下次导出默认打开上次成功保存的目录。成功后，“保存封面图”上方出现“打开导出文件夹”，定位最近成功导出的图片；取消或失败保留上次目标。点击“保存封面图”后选择覆盖或创建 v1、v2… 图片和视频副本。保存会同时更新图片与视频的配对标识及所选封面时刻，并保留原拍摄日期等有效信息。新图、视频及配对信息先校验，再提交；失败时尝试恢复原组，恢复遇到占用或外部改动会保留临时资料并提示处理。未完成的保存需先恢复后才能继续。覆盖保存前提示“覆盖原图，无法撤销”；覆盖成功不留备份且无法撤销；视频画面和声音保留，必要元数据随新封面更新。新封面统一保存为 HEIC；覆盖成功后清理同目录同名 JPG／JPEG，只保留新 HEIC 与同名 MOV。创建副本保留原组；取消不改文件。
7. 设置中可选缓存位置：本机用户目录、软件目录 data/cache、照片目录的隐藏 LiveViewer Cache。图库缓存复用有效记录、只更新变化项；“打开缓存位置”查看实际目录；看图右键菜单中的“深入校验当前图库”检查内容变化，可取消。清理缩略图保留手动择图。
8. 外观可选深色、浅色或跟随 Windows 应用模式。设置开关蓝色为开启、灰色为关闭。单指上下拖动可滚动设置页，从开关或下拉框上起滑也只滚动页面，轻点才操作控件。滚轮在下拉框或数字输入框上仅滚动页面；展开下拉列表后可滚动选项，数字可输入或点击箭头调整。
9. 单张界面点“独立预览窗”，打开带标题栏的最大化预览，主窗保留全览。拖动标题栏放到目标位置后，点击主窗“全屏”按钮进入预览全屏；F11 也可切换。打开“触控板”，可在整个操作面上滑动、缩放、拖动或长按控制照片，不显示缩略图；松手停止播放，视频仅在预览窗播放。触控板可停靠左／右／底部或独立浮动，拖动分隔条调尺寸。全屏中用 Esc、F11 或退出手势，以及“返回主窗口”或关闭预览窗，都会回到主窗单张并关闭触控板，保留当前照片和缩放；关闭触控板不关闭预览。预览按保存的窗口几何恢复到可用屏幕后最大化；进入全屏前还原或移动窗口不会收回预览。触控板的位置和尺寸分别记忆，软件下次启动仍为普通主窗。

快捷键以设置为准，升级保留设置。罗技 Options 中请将 LiveViewer 拇指滚轮设为“水平滚动”。硬盘断开后重连并重新扫描。
