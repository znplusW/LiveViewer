# LiveViewer 使用指南

## 使用

1. 将 ZIP 内整个 `LiveViewer-Windows-x64-v版本号` 文件夹解压到可写位置，运行其中的 `LiveViewer.exe`。文件夹名与 ZIP 文件名一致（不含 `.zip`），例如 `LiveViewer-Windows-x64-v1.0`。
2. 点击“添加文件夹”，可用 Ctrl／Shift 一次选择多个目录，追加到已打开的图库，默认递归扫描。侧栏点击左侧复选框可独立勾选各层目录，决定全览、胶片条和翻页范围。普通点击名称只记录范围起点，不改变勾选；随后按住 Shift 点击另一个目录可选中两者之间的范围。按住 Ctrl 从名称或空白处拖框，会反转框内目录的勾选状态：已选取消、未选选中，框外保持不变；拖动中松开 Ctrl 则取消本次框选。Ctrl+A 全选。路径旁的“显示列表／隐藏列表”控制侧栏。搜索范围可选“已选文件夹”或“全局”（全部已导入），清空搜索恢复勾选范围。
   侧栏右键可从软件中移除已选目录，或移除指定目录及其子目录；不删除硬盘文件，重新导入可恢复。
3. 点击缩略图查看图片，或切换到全览快速定位。
   全览和胶片条的 LIVE 标记固定在缩略图单元框内左上角，减少对图片的遮挡；小缩略图以圆点表示，空间充足时显示完整标记。顶部文件名仍支持鼠标拖选和复制。悬停文件名可查看完整名称和所在文件夹路径；当文件名发生省略时，双击文件名文字区域直接复制原始完整名称及扩展名，不含路径。照片本身的双击缩放行为不变。
4. 有 LIVE 标记的图片，按住鼠标左键、单指长按或默认空格键播放视频；松开立即恢复静态图片。触控板需明确按下实体按键；轻触两下后保持第二次接触，停顿再拖动只平移，不触发播放。
5. 默认单击 `P` 键从头播放一遍，松开按键继续播放，播完恢复照片。此操作不采用循环设置。升级时保留原有按住播放快捷键；如果原来已使用 `P`，单击播放初始使用 `F9`，可在设置中更改。

设置中可分别更改“按住播放”“单击播放一遍”和“显示／隐藏胶片条”的快捷键；这些功能须使用不同按键。还可更改按住播放时的播放一次／循环、静音、长按时间、是否递归、缓存上限，以及放大时的播放方式。

设置开关蓝色为开启、灰色为关闭。滚轮停在关闭的下拉框或数字输入框上时只滚动设置页面，避免误改参数；展开下拉列表后保留正常选择，数字可直接输入或点击箭头调整。

外观可选深色（默认）、浅色和跟随 Windows；跟随模式按 Windows 的应用颜色模式自动更新。使用 PowerToys Light Switch 时，应将切换范围设为包含 Apps（应用）。[微软官方说明](https://learn.microsoft.com/en-us/windows/powertoys/light-switch)

“自动播放 Live Photo”默认关闭。开启后，从下一次切换到 Live Photo 开始自动播放一遍，播完恢复照片；不采用按住播放的循环设置。普通全览和更改封面图保存后的检查画面不自动播放。独立预览开启时，主窗选中新 Live Photo 可在预览窗自动播放；移动布局不重播。

## 更改封面图

在 Live Photo 的图片右键菜单中选择“更改封面图”，用鼠标或单指触屏拖动时间轴、长按左右方向键时持续预览，精确选择视频中的某一帧；可变帧率视频也按实际帧逐张切换。窗口支持最大化；图片与 MOV 的关联标识一致时，时间轴优先读取实际封面时间标记；缺失或标识不符时按画面近似匹配并提示不确定性。预览按窗口缩小，保存使用完整视频帧分辨率，可能低于原始照片。点击“保存封面图”后才显示保存方式选择；取消选择会返回编辑器。

编辑器预览支持滚轮／双指缩放及放大后单指拖动。右键“导出静帧画面…”可另存全分辨率 PNG、JPG／JPEG 或 HEIC，仅写入选定图片；原封面图与 MOV 保持原样。下次默认打开上次成功导出的目录，取消或失败不改变记录；导出结果显示完整路径。成功后，“保存封面图”上方会出现“打开导出文件夹”，打开并选中最近成功导出的图片；改变时间轴、取消或失败不会改变这个目标。

- 默认“创建副本”：在原目录同时创建同版本号的图片和视频，例如 `照片 v1.HEIC` 与 `照片 v1.MOV`；再次保存会选择可用的 `v2` 等名称。原图和原视频保持不变。
- “覆盖原组”：确认前提示“覆盖原图，无法撤销”；永久替换当前静态图片，并同步更新 MOV 的关联标识及封面时刻；视频画面和声音不重编码。**成功后不保留永久备份，也不能在 LiveViewer 中撤销**。
- JPG／JPEG／HEIC 原组更改封面后统一生成 HEIC 与同名 MOV，二者使用新的共同配对标识；沿用原机时间轨结构，将封面标记移到所选帧的实际呈现时间。覆盖成功后清理同目录同名 JPG／JPEG；创建副本保留原组。保存前检查来源未变、图片完整解码、音视频编码数据和配对信息；两份文件暂存校验后提交，异常尝试恢复原组。若遇到外部改动等恢复冲突，会保留临时恢复资料并明确报错，不覆盖外部修改。

封面处理已修复 iPhone MOV 中合法本地 `alis` 引用被误拒、`mebx` 样本头偏移错误的问题；新写入的时间标记使用 Apple 标准结构。

独立09工具已通过原HEIC和原JPG组经爱思助手导回iPhone的真人验收：单一LIVE、新封面、画面和声音正常。此前封面集成基线通过782项桌面回归及源码、冻结EXE各70项自检，v0.9在此基础上仅更名；这些记录不代表v1.0新界面已验收，整合后的手机回导仍待真人确认。方法差异和完整参考代码见 `docs/LivePhoto-07-08-09-方法与代码.html`。通过爱思助手“导入实况照片”一起导入同名HEIC和MOV。“导出静帧画面”仍只导出独立图片。

逐帧读取和 HEIC 写入组件随绿色版提供，无需另外安装软件。文件过长、画面过大、MOV 结构尚不支持或文件在编辑中被修改时，编辑器会停止保存并提示原因。

## 全览与全屏

顶部改为保留 LiveViewer 名称的紧凑工具栏；空图库突出“添加文件夹”，有照片后降低该入口的视觉强调。全览保留左侧文件夹栏，顶部一行搜索、筛选、排序，下方直接显示照片网格；单张相关控件不再常驻整行，选中照片后按需提供相关操作。

- “类型筛选”下拉列表可以同时勾选 Live Photos 和静态照片，也可以仅勾选其中一类。两类均未勾选时列表为空；“待检查”可进一步限制到配对判断尚待确认的项目。
- 全览中可以单指上下滑动滚动照片列表；滑动不会打开照片，轻点缩略图打开单张照片。鼠标滚轮仍可滚动。
- 全览可双指张合，或按 `Ctrl` 加加号／减号，调整缩略图大小；放大时每行显示更少，缩小时每行显示更多。缩放手势不会打开照片或播放视频。
- 点击全屏按钮或按 `F11`，立即隐藏标题、目录、工具和信息栏。在全览中进入全屏会保留全览；在单张查看中进入全屏只保留图片，已开启胶片条时保留图片和胶片条。
- 全屏中移动鼠标不会重新显示工具栏。按 `Esc` 或再次按 `F11` 可退出全屏。设置中的“退出全屏手势”仅提供“屏幕上沿下滑”，默认开启，取消勾选即可关闭。手势与 `Esc` 效果相同。独立预览退出全屏时收回主窗单张，并关闭触控板。
- 单张照片在全屏时，左上角固定显示 LIVE 标记；静态照片和全览不显示该标记，缩放和平移不会移动标记。
- 普通单张查看中按 `Esc` 返回全览。全屏单张中先按一次 `Esc` 退出全屏，再按一次返回全览。
- 默认 `F` 键显示／隐藏胶片条，也可在设置中自定义快捷键。单击照片不改变胶片条状态，可通过按钮或快捷键控制。胶片条的“左侧／右侧／底部”按钮直接切换位置，`X` 关闭；竖排滚动条放在靠外侧，左侧竖排的滚动条在左边。横排左右滑、竖排上下滑，轻点选图；拖动靠照片一侧的分隔条，同步调整宽度／高度与预览大小。软件分别记住横排高度、竖排宽度及上次位置；小窗口临时缩小不会覆盖记忆，全览隐藏胶片条。
- 图片右键菜单的“以其他软件打开”会列出 Windows 为当前图片格式推荐的应用，选择后直接用该应用打开静态图片；列表取决于本机安装和注册的应用。菜单保留 Windows 应用选择入口，以便选择其他软件。

“打开所在文件夹”会在 Windows 资源管理器中定位并选中当前静态图片，不会改用对应 MOV。

## 独立预览与触控板

单张界面点击“独立预览窗”，打开最大化预览并保留标题栏，主窗保留全览并可继续选图。可拖动标题栏，把预览放到目标位置，再点击主窗“全屏”按钮进入预览全屏；F11 仍可切换全屏。预览内容只有照片／视频、LIVE 标记和缩放导航小图。全屏中按 Esc、F11 或使用已启用的退出手势，都会收回主窗单张并关闭触控板；关闭预览窗也可收回。

打开“触控板”，整个操作面均可滑动翻页、缩放、拖动或长按播放，不显示缩略图，也不受照片黑边范围限制；松手停止播放，鼠标右键可打开菜单。它控制同一张预览照片，视频仅在预览窗播放。触控板可停靠左侧、右侧、底部或独立浮动，拖动相邻分隔条调整大小；“收回触控板”返回记忆的停靠位置。

点“返回主窗口”或预览右键中的同名选项，同样回到主窗单张查看，保留当前照片和缩放。关闭触控板只隐藏它，主窗关闭则退出全部窗口。预览根据保存的窗口几何恢复到当前可用屏幕后最大化；进入全屏前还原或移动窗口会保留独立预览。触控板的浮动位置、停靠位置及不同方向的尺寸分别记忆，小窗口临时限制不覆盖记忆。下次启动仍为普通主窗。

## 图片与视频规则

- `.jpg`、`.jpeg`、`.heic` 仅与**同一目录、同一不含扩展名的文件名**的 `.mov` 配对，忽略扩展名大小写。不同子文件夹之间不配对。
- 没有对应 MOV 的 JPG／JPEG／HEIC 仍可作为普通图片浏览。
- PNG、WebP、BMP、GIF、TIF／TIFF、AVIF 独立浏览，不参与 Live Photo 配对。当前 GIF 显示首帧，TIFF 显示第一页。
- 同名候选视觉内容相同时优先 HEIC；只有 JPG／JPEG 时优先较高分辨率。
- 内容不同时，结合视频代表帧及可获得的原始关联信息自动择图，未选中的不同内容保留为普通照片。
- 判断不明确时仍自动选择并标记，完全打平优先 HEIC。通过“静态来源”可手动改选，软件会记住选择。

自动择图使用本地启发式图像比较，无法保证每组都正确。它不调用云端 AI，也不会上传照片。原始 Apple Live Photo 的特殊缓入缓出、HDR／Dolby Vision 精确色调还原不作为此版的已验证能力；此版按配对 MOV 播放整段视频。

## 缩放与触屏

- 适应窗口时，单指在图片或图片外空白区域左右滑动均可切换照片。
- 双指缩放；放大后单指或触控板双击拖曳平移，第二次按住时不会短暂播放 Live 视频。鼠标竖向滚轮缩放、左键拖动平移。放大时右下角导航小图显示整图与当前视口，点击或拖动可定位；适应窗口时隐藏。
- 未放大时，鼠标水平滚轮始终切换上一张／下一张；放大后才按“放大时水平滚轮”设置，选择翻页或左右平移。触控板的横向滚动也采用该规则。
- 直接看图时，单指在图片内容上长按用于播放，不触发 Windows 的长按右键；在图片外的空白区域长按仍保留右键功能。触控板的整个操作面都用于控制照片。
- 鼠标双击或触屏双击，在适应窗口和两倍放大之间平滑切换，并以点击位置为缩放中心；默认方向键或滑动手势可翻页。
- 默认视频沿用当前画面中心与相对缩放；也可设置临时完整播放，松开后恢复照片原来的视口。
- 按住播放选择单次模式时，视频播完即恢复照片；持续按住不会自动重新播放。循环模式持续到松开。单击播放快捷键始终只播放一遍。
- 翻页、打开设置、离开软件和取消触摸均停止按住播放；在同一软件的主窗、预览窗和触控板之间操作时保持控制一致。

图片和视频可能存在分辨率、防抖裁切、构图和色彩差异，视频保持原比例并映射至同一画布，不能保证所有文件像素级无缝衔接。

## 大量图片与缓存

文件发现与图片解码分开执行；索引阶段不打开每张图片或解码每个视频。缩略图按需生成，当前照片有独立的优先处理通道，快速连续切图时跳过已过时的排队任务；配对分析在后台进行，先显示当前照片。完整图片在放大时渐进载入。

设置保留原有两种缓存位置，并增加随图库保存：

| 缓存位置 | 目录 |
| --- | --- |
| 本机用户目录 | `%LOCALAPPDATA%\LiveViewer\cache` |
| 软件目录 | `LiveViewer.exe` 同目录的 `data\cache` |
| 照片文件夹 | 每个已导入照片根目录下隐藏的 `LiveViewer Cache` |

默认保持原有缓存位置；只有选用照片文件夹缓存时才在图库内建立缓存。已有有效缩略图和配对结果会尽量复用；按文件信息增量判断，仅为新增或变化项目重新生成。缓存内部使用相对图库路径，整库移动或换盘符后仍可复用；缓存和编辑临时目录不参与照片扫描。

默认缩略图磁盘上限 2 GB，可在设置中调整。清理缩略图保留手动择图；看图右键菜单中的“深入校验当前图库”会在后台读取文件内容以检查同大小、同时间等变化，可取消。日常浏览不默认完整计算全库校验值。图库不可写、缓存不兼容或被其他进程占用时，会使用本机缓存并提示实际位置。

设置的保存位置仍可选择跟随软件目录，与缓存位置分别管理。浏览不会改动原图或视频；选择图库缓存会写入其隐藏缓存目录，原媒体仅在“更改封面图”中确认保存时写入。移动硬盘断开时请重新连接，必要时重新扫描目录。
