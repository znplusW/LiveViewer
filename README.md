# LiveViewer

Windows 11 x64 本地 Live Photo 与普通图片查看器。当前版本 v0.7.0。绿色版解压后运行 `LiveViewer.exe`，请保留同目录的 `_internal` 文件夹。

每个绿色版 ZIP 的程序文件夹内附带两份简明文档：`使用说明.txt` 和 `产品说明.txt`；后者合并更新历史与功能设计，便于直接随软件分发。

## 使用

1. 将 ZIP 内整个 `LiveViewer-Windows-x64-v版本号` 文件夹解压到可写位置，运行其中的 `LiveViewer.exe`。文件夹名与 ZIP 文件名一致（不含 `.zip`），例如 `LiveViewer-Windows-x64-v0.7.0`。
2. 点击“打开文件夹”，选择照片所在目录。默认递归包含子文件夹。
3. 点击缩略图查看图片，或切换网格总览快速定位。
   顶部文件名支持鼠标拖选和复制。
4. 有 LIVE 标记的图片，按住鼠标左键、单指长按或默认空格键播放视频；松开立即恢复静态图片。
5. 默认单击 `P` 键从头播放一遍，松开按键继续播放，播完恢复照片。此操作不采用循环设置。升级时保留原有按住播放快捷键；如果原来已使用 `P`，单击播放初始使用 `F9`，可在设置中更改。

设置中可分别更改“按住播放”“单击播放一遍”和“显示／隐藏胶片条”的快捷键；这些功能须使用不同按键。还可更改按住播放时的播放一次／循环、静音、长按时间、是否递归、缓存上限，以及放大时的播放方式。

“自动播放 Live Photo”默认关闭。开启后，从下一次切换到 Live Photo 开始自动播放一遍，播完恢复照片；不采用按住播放的循环设置。总览和更改封面图保存后的检查画面不自动播放。

## 更改封面图

在 Live Photo 的图片右键菜单中选择“更改封面图”，用鼠标或单指触屏拖动时间轴、长按左右方向键时持续预览，精确选择视频中的某一帧；可变帧率视频也按实际帧逐张切换。窗口支持最大化；时间轴标记原封面图的画面匹配位置，无法可靠区分时提示匹配不确定。预览按窗口缩小，保存使用完整视频帧分辨率，可能低于原始照片。点击“保存封面图”后才显示保存方式选择；取消选择会返回编辑器。

- 默认“创建副本”：在原目录同时创建同版本号的图片和视频，例如 `照片 v1.jpg` 与 `照片 v1.MOV`；再次保存会选择可用的 `v2` 等名称。原图和原视频保持不变。
- “覆盖原图”：永久替换当前静态图片，**不保留备份，也不能在 LiveViewer 中撤销**；原视频不变。
- JPG／JPEG／HEIC 保存后保持原格式，HEIC 不会改成 JPG；取消编辑不会更改原文件。保存前会验证来源文件和完整图片解码，成功后再更新照片库。

逐帧读取和 HEIC 写入组件随绿色版提供，无需另外安装软件。文件过长、画面过大或文件在编辑中被修改时，编辑器会停止保存并提示原因。

## 总览与全屏

- “类型筛选”下拉列表可以同时勾选 Live Photos 和静态照片，也可以仅勾选其中一类。两类均未勾选时列表为空；“待检查”可进一步限制到配对判断尚待确认的项目。
- 总览中可以单指上下滑动滚动照片列表；滑动不会打开照片，轻点缩略图打开单张照片。鼠标滚轮仍可滚动。
- 点击全屏按钮或按 `F11`，立即隐藏标题、目录、工具和信息栏。在总览中进入全屏会保留总览；在单张查看中进入全屏只保留图片，已开启胶片条时保留图片和胶片条。
- 全屏中移动鼠标不会重新显示工具栏。按 `Esc` 或再次按 `F11` 退出全屏。
- 单张照片在全屏时，左上角固定显示 LIVE 标记；静态照片和总览不显示该标记，缩放和平移不会移动标记。
- 普通单张查看中按 `Esc` 返回总览。全屏单张中先按一次 `Esc` 退出全屏，再按一次返回总览。
- 默认 `F` 键显示／隐藏胶片条，也可在设置中自定义快捷键；胶片条顶端向下按钮可直接隐藏，总览不显示胶片条。
- 图片右键菜单的“以其他软件打开”会列出 Windows 为当前图片格式推荐的应用，选择后直接用该应用打开静态图片；列表取决于本机安装和注册的应用。菜单保留 Windows 应用选择入口，以便选择其他软件。

“打开所在文件夹”会在 Windows 资源管理器中定位并选中当前静态图片，不会改用对应 MOV。

## 图片与视频规则

- `.jpg`、`.jpeg`、`.heic` 仅与**同一目录、同一不含扩展名的文件名**的 `.mov` 配对，忽略扩展名大小写。不同子文件夹之间不配对。
- 没有对应 MOV 的 JPG／JPEG／HEIC 仍可作为普通图片浏览。
- PNG、WebP、BMP、GIF、TIF／TIFF、AVIF 独立浏览，不参与 Live Photo 配对。当前 GIF 显示首帧，TIFF 显示第一页。
- 同名候选视觉内容相同时优先 HEIC；只有 JPG／JPEG 时优先较高分辨率。
- 内容不同时，结合视频代表帧及可获得的原始关联信息自动择图，未选中的不同内容保留为普通照片。
- 判断不明确时仍自动选择并标记，完全打平优先 HEIC。通过“静态来源”可手动改选，软件会记住选择。

自动择图使用本地启发式图像比较，无法保证每组都正确。它不调用云端 AI，也不会上传照片。原始 Apple Live Photo 的特殊缓入缓出、HDR／Dolby Vision 精确色调还原不作为此版的已验证能力；此版按配对 MOV 播放整段视频。

## 缩放与触屏

- 适应窗口时，单指在图片或图片外空白区域左右滑动均可切换照片。
- 双指缩放；放大后单指拖动平移。鼠标竖向滚轮缩放、左键拖动平移。
- 鼠标横向滚轮默认切换上一张／下一张，放大后也保持翻页；设置中可改为放大后左右移动画面，此模式在适应窗口时不翻页。触控板的横向滚动也采用该设置。
- 单指在图片内容上长按时用于播放，不触发 Windows 的长按右键；在图片外的空白区域长按仍保留右键功能。
- 鼠标双击或触屏双击，在适应窗口和两倍放大之间平滑切换，并以点击位置为缩放中心；默认方向键和上一张／下一张按钮可翻页。
- 默认视频沿用当前画面中心与相对缩放；也可设置临时完整播放，松开后恢复照片原来的视口。
- 按住播放选择单次模式时，视频播完即恢复照片；持续按住不会自动重新播放。循环模式持续到松开。单击播放快捷键始终只播放一遍。
- 翻页、打开设置、失去焦点和取消触摸均停止播放。

图片和视频可能存在分辨率、防抖裁切、构图和色彩差异，视频保持原比例并映射至同一画布，不能保证所有文件像素级无缝衔接。

## 大量图片与缓存

文件发现与图片解码分开执行；索引阶段不打开每张图片或解码每个视频。缩略图按需生成，当前照片有独立的优先处理通道，快速连续切图时跳过已过时的排队任务；配对分析在后台进行，先显示当前照片。完整图片在放大时渐进载入。

设置保留原有两种缓存位置，并增加随图库保存：

| 缓存位置 | 目录 |
| --- | --- |
| 本机用户目录 | `%LOCALAPPDATA%\LiveViewer\cache` |
| 软件目录 | `LiveViewer.exe` 同目录的 `data\cache` |
| 照片文件夹 | 当前照片根目录下隐藏的 `LiveViewer Cache` |

默认保持原有缓存位置；只有选用照片文件夹缓存时才在图库内建立缓存。已有有效缩略图和配对结果会尽量复用；按文件信息增量判断，仅为新增或变化项目重新生成。缓存内部使用相对图库路径，整库移动或换盘符后仍可复用；缓存和编辑临时目录不参与照片扫描。

默认缩略图磁盘上限 2 GB，可在设置中调整。清理缩略图保留手动择图；看图右键菜单中的“深入校验当前图库”会在后台读取文件内容以检查同大小、同时间等变化，可取消。日常浏览不默认完整计算全库校验值。图库不可写、缓存不兼容或被其他进程占用时，会使用本机缓存并提示实际位置。

设置的保存位置仍可选择跟随软件目录，与缓存位置分别管理。浏览不会改动原图或视频；选择图库缓存会写入其隐藏缓存目录，原媒体仅在“更改封面图”中确认保存时写入。移动硬盘断开时请重新连接，必要时重新扫描目录。

## 验证范围

自动测试覆盖同目录配对、JPEG 扩展名、子目录隔离、普通图片、重复候选分析、缓存位置／迁移复用／增量失效／上限、播放状态、类型筛选、单张／总览全屏、缩放动画、模拟触屏滚动、快速切图任务调度和更改封面图事务。还会实际解码 HEIC／AVIF，播放合成 H.264／HEVC MOV（含带旋转信息的竖屏素材），验证可变帧率视频的精确帧编号与保存，并在 Windows x64 冻结 EXE 内再次验证。

视频使用完整解码帧更新图片画布，以处理部分视频播放时出现的横向错位。不同显卡、视频编码参数和 HDR 色彩仍可能产生差异，发现异常时请保留原始视频与截图用于复查。

这些测试使用本项目生成的素材。真实 iPhone 导出、不同电脑的显卡与触屏驱动、移动机械硬盘的首次读取速度，仍需在使用设备上验收。不要将 Windows Server 云端通过直接理解为所有 Windows 11 设备已验证。

## 源代码与构建

使用 Python 3.12。运行依赖见 `requirements.txt`，开发与打包依赖见 `requirements-build.txt`。PyAV 只生成开发测试素材，不随成品分发。

Windows 构建会根据 `dependencies/` 中的固定版本与 SHA-256 下载 LGPL 共享版 FFmpeg／ffprobe，并从固定源码构建 HEIC 编码组件。FFmpeg 工具和其 DLL 位于独立目录，不与 Qt 的播放库合并；原始许可证、构建配置及对应源码地址随成品保留。

```text
python -m pip install -r requirements-build.txt
python scripts/fetch_frame_tools.py
python scripts/build_heic_encoder.py
python -m unittest discover -s tests -v
python launch.py --self-test --fixtures tests/fixtures --report-dir reports/source
python scripts/build_windows.py
```

GitHub Actions 的 “Build and test Windows x64” 仅手动触发，完成后下载 LiveViewer 构建产物。绿色版 ZIP、对应源码 ZIP 和 SHA-256 校验值一起提供。源码中不包含用户的照片或凭据。

第三方组件的许可证、版本与对应源码地址见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。
